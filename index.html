小一 AI 語音助理

說一聲「小一小一」，事情就交給它。

小一是免費的中文語音助理。喚醒之後可以查天氣、開導航、計算、播放 YouTube，也能把回答朗讀出來。聽錯的地名或算式，會先用 Gemini 校正再執行。

一分鐘認識小一：喚醒、指令與主要功能。

它能幫你做什麼

語音和打字都可以。聽寫與朗讀使用瀏覽器內建語音；需要 Gemini 糾錯時，金鑰只存在你自己的裝置上。

語音喚醒

說「小一小一」或「你好」之後，才會把後面的話當成指令，避免一直誤觸。

Gemini 糾錯

地名、算式若聽錯，會先校正再查天氣、導航或計算，減少跑錯地方。

天氣

說「查天氣」，依目前位置回報天氣，也可以用語音把結果唸出來。

導航

說出目的地後先確認，再打開 Google 地圖。說「不對」可以取消。

計算

直接說算式，例如「100 加 25」。小一會算出結果並朗讀。

YouTube 與朗讀

用語音指定歌曲或影片即可播放。文字也能朗讀，語速和語音可在設定裡調整。

怎麼開始說話

用 Chrome 或 Edge 開啟，登入後允許麥克風。語言支援繁體中文、簡體中文、英文與日文。

登入帳號

使用 Gmail 註冊或登入。註冊需要郵件驗證碼，密碼至少 8 碼。每位帳號有自己的對話紀錄。

喚醒小一

按下麥克風，或直接說「小一小一」、「你好」。看到正在聽取後，再講完整指令。

也可以打字

不方便說話時，在輸入框打字傳送。同一套天氣、導航、計算與播放都能用。

下載與安裝

手機請下載 Android App。也可以直接開網頁版，或在 Windows 本機執行。

本機版

下載專案後在自己的電腦執行。需要已安裝 Python，以及 Chrome 或 Edge。

  1. 下載 ZIP 並解壓縮。
  2. 進入解壓後的資料夾。

Chrome／Edge

瀏覽器擴充功能

在網頁上反白文字即可朗讀，也可在彈出視窗聽寫與調整語速。此功能使用瀏覽器內建語音，不需要 API 金鑰。

  1. 先下載上方的 ZIP，打開其中的 extension 資料夾。
  2. 到擴充功能頁面，開啟「開發人員模式」。
  3. 選擇「載入未封裝項目」，指定 extension 資料夾。
